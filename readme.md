## jmp説明書

#### JmpList
### 📝 JmpList - ショートカット一覧（完全版）
| 機能                | primaryキー | secondaryキー       | 説明                                |
|---------------------|-------------|---------------------|-------------------------------------|
| **常に最前面**         | `Tab`        |                     | ウィンドウを常に最前面に固定/解除       |
| **登録**             | `W`          |                     | 新しい項目の追加ウィンドウを開く         |
| **閉じる**           | `X`          | `Esc`               | アプリケーションを終了                 |
| **消去**             | `D`          | `Delete`            | 選択された項目を削除                   |
| **全消去**           | `A`          |                     | すべてのリストを削除（確認あり）         |
| **選択**             | `Enter`      | `ダブルクリック`     | 項目を選択して `jmp()` を実行         |
| **リスト下へ移動**     | `J`          | `↓ (Down Arrow)`    | リスト内の下の項目に移動               |
| **リスト上へ移動**     | `K`          | `↑ (Up Arrow)`      | リスト内の上の項目に移動               |
| **カラー変更**        | `C`          |                     | 選択項目のテキスト色を変更             |
| **文字の太さ切替**     | `B`          |                     | 太字と通常文字を切り替える             |
| **透明度変更**        | `0`〜`9`     |                     | ウィンドウの透明度を `10%`〜`100%`に変更 |
| **タイムスタンプ更新** | `T`          |                     | 選択項目のタイムスタンプを現在に更新     |


#### jmp登録
説明とフォルダパスを入力して
エンターを押すと登録されます
